安装python包
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple

创建向量表
sqlplus aiarag/Aiarag123456@//192.168.56.110:1521/orclpdb1
create table ovs(
id         number generated by default as identity primary key,
text       clob,
metadata   clob,
embedding  vector(1024, float32)
);
创建索引
alter table ovs add constraint json_chk check (metadata is json);
create index json_idx on ovs(metadata.source);
收集统计信息
exec dbms_stats.gather_table_stats('AIARAG','OVS');
所有知识库文件加载后，创建向量索引
create vector index ovs_idx on ovs(embedding) organization inmemory neighbor graph
distance cosine
with target accuracy 90
parameters (type hnsw, neighbors 32, efconstruction 100)
parallel 4;

编辑config.json文件
knowledge_file 这是知识库文件的参数配置
  upload_dir 服务器本地路径，存放上传的知识库文件，最后不带/
  download_method 知识库文件下载方法。有效值是local和http。如果是本地下载，该值是local。如果是http下载，该值是http
  http_url 如果是http下载知识库文件，填写http的url地址，最后不带/
vdb_config 这是向量数据库的参数配置
  dsn 向量数据库的连接地址
  username 向量数据库的用户名
  password 向量数据库的用户密码
  table_name 向量数据库的表名
  poolminsize 数据库连接池的初始连接数
  poolmaxsize 数据库连接池的最大连接数
  poolincrement 数据库连接池的每次增长
embedding_model 这是嵌入模型的参数配置
  path 嵌入模型的本地路径
rerank_model 这是Rerank模型的参数配置
  path Rerank模型的本地路径
  max_length Rerank模型的最大长度
  device Rerank模型的设备，有效值是cpu和gpu
  score chunk的最小分数
